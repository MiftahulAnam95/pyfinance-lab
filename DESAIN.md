# Arahan desain — PyFinance Lab

## Gagasan visual
Ruang praktikum digital, bukan dashboard bank. Bilangan Rupiah dan jejak terminal menjadi bukti yang bisa diperiksa pengguna. Hero menampilkan manfaat proyek, dua aksi, dan cuplikan keluaran yang diberi label. Cuplikan tidak menjalankan kode. Terminal, garis pemisah, dan grid UI disusun dari HTML/CSS; tidak ada foto, ilustrasi stok, atau logo pendukung.

- **Hierarki:** Space Grotesk untuk judul; Manrope untuk navigasi dan prosa; JetBrains Mono untuk angka, terminal, langkah, dan label kecil. Latar arang, panel biru-abu, teks putih lembut, aksen mint untuk tindakan atau fokus. Pengeluaran punya tanda minus selain warna.
- **Struktur:** beranda → peta dua belas bab → tujuan/prasyarat → bacaan dan contoh → pembahasan/latihan → rangkuman. Bilah sisi desktop memuat seluruh kurikulum dan progres. Mobile memakai dialog navigasi; tautan bab tetap dapat diakses melalui peta statis.
- **Gerak:** tombol langsung aktif tanpa menunggu animasi. Terminal bergeser pendek ke posisi akhirnya; label kurikulum mendapat gerak ringan ketika mendekati viewport. Keadaan default tetap terlihat, tanpa scrub atau pemecahan heading. Reduced motion mengikuti posisi statis dan gulir asli.
- **Lenis vs Locomotive Scroll:** keduanya dapat menghaluskan gulir (versi Locomotive modern pun menggunakan Lenis di bawahnya). Memasang Locomotive tidak menambah manfaat pada halaman tanpa parallax. Dipilih Lenis saja untuk integrasi ticker dan `ScrollTrigger.update`, dengan penghancuran instance dan pelepasan listener melalui cleanup GSAP media context.
- **Three.js:** tidak digunakan; tampilan terminal dan tabel data lebih cepat, lebih terbaca dan lebih mudah dioperasikan dengan keyboard jika dibangun dengan HTML.
- **Skill:** tidak ditemukan `SKILL.md` desain yang terpasang pada lokasi skill/workspace yang diperiksa. Implementasi mengikuti prinsip yang ditulis di brief; tidak mengklaim penggunaan paket skill yang tak tersedia.
- **Mode gelap/terang:** gelap tetap bawaan. Semua warna menjadi token di `src/style.css`; mode terang hanya mengganti nilai token pada `:root[data-theme='light']`, bukan menulis ulang komponen. Aksen mint digelapkan agar tetap lolos kontras AA di atas latar terang, sementara area terminal, blok kode, dan contoh keluaran sengaja tetap gelap karena bagian itu meniru layar terminal. Toggle berada di topbar dan side-footer, statusnya terlihat dari `aria-pressed` dan label "Aktifkan mode terang/gelap".
- **Aset:** ikon Solar Linear oleh 480 Design, CC BY 4.0, dipilih dari data Iconify dan disematkan sebagai SVG inline. Warna diatur lewat CSS; favicon memakai satu ikon dengan latar baru. Font sumber terbuka lewat Fontsource, dilayani sendiri. Kredit dan lisensi ada di `public/licenses/`.
