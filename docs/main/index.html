BAB 06 / 12

Bedah main.py

Ikuti keputusan program dari menu sampai keluar.

TUJUAN BELAJAR

Mengikuti cabang menu, aliran nilai, dan kondisi keluarnya loop.

SEBELUM MULAI

Pahami input, kondisional, while, dan import.

Titik masuk

Python menetapkan __name__ menjadi __main__ saat file dijalankan langsung. Penjaga if mencegah menu otomatis berjalan jika file hanya diimpor. main membuat satu list kosong sebelum loop; jika diletakkan di dalam loop, tiap putaran akan menghapus riwayat sesi.

Satu putaran menu

menu mencetak pilihan. input menerima string; pilihan 1/2 menentukan jenis, lalu baca_nominal memeriksa nominal. Untuk 1, kategori otomatis “Uang saku”; untuk 2, pengguna mengisinya. tambah menerima list dan memperbaruinya. ValueError dari pencatatan ditangkap dan menu kembali tanpa menyimpan masukan buruk.

Baca, ulang, keluar

Pilihan 3 menampilkan saldo; 4 memanggil riwayat; 5 memanggil per_kategori. Pilihan salah menampilkan pesan. Pilihan 6 menjalankan break; EOF atau Ctrl+C di terminal menghentikan sesi lewat penanganan terpisah. Tidak ada penulisan ke disk.

Kode lengkap: main.py

Simpan dengan nama ini bersama tiga file lainnya. Jalankan python3 main.py dari folder proyek; file ini adalah titik masuk.

main.py
Unduh 
"""Jalankan dengan python main.py dari folder ini."""

from pencatat import baca_nominal, tambah, saldo
from laporan import riwayat, per_kategori
from tampilan import menu, rupiah


def main():
    data = []
    while True:
        menu()
        pilihan = input('Pilih menu [1–6]: ').strip(' \t\r\n')
        if pilihan in ('1', '2'):
            jenis = 'masuk' if pilihan == '1' else 'keluar'
            try:
                nominal = baca_nominal(input('Nominal (Rp): '))
                kategori = 'Uang saku' if jenis == 'masuk' else input('Kategori: ')
                tambah(data, jenis, nominal, kategori)
                print('Transaksi tersimpan.')
            except ValueError as error:
                print(f'Input ditolak: {error}')
        elif pilihan == '3':
            print(f'Saldo: {rupiah(saldo(data))}')
        elif pilihan == '4':
            print(riwayat(data))
        elif pilihan == '5':
            print(per_kategori(data))
        elif pilihan == '6':
            print('Sesi selesai. Data tidak disimpan.')
            break
        else:
            print('Pilihan tidak dikenal. Pilih 1–6.')


if __name__ == '__main__':
    try:
        main()
    except (EOFError, KeyboardInterrupt):
        print('\nSesi dihentikan. Data tidak disimpan.')
