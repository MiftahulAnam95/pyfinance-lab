Alur & Jejak Data

Ikuti perubahan data setiap kali pengguna memilih menu.

TUJUAN BELAJAR

Menelusuri input, fungsi yang dipanggil, dan keadaan data setelah tindakan.

SEBELUM MULAI

Kenali peran keempat file; kamu tidak harus hafal semua baris.

Jejak data adalah foto sebelum dan sesudah

Sebuah program tidak sekadar mengeluarkan teks. Data di memori juga bisa berubah. Gunakan penelusur di bawah untuk membedakan tindakan tulis (menu 1/2) dan tindakan baca (3/4/5).

Mulai → catat → baca → keluar

main membuat daftar kosong. Penambahan yang sah mengubah daftar yang sama. Tampilan dan laporan hanya membacanya. Saat sesi selesai, daftar tidak digunakan lagi; sesi berikutnya selalu dimulai kosong.

Cabang kesalahan

Contoh 25.000 ditolak sebelum kategori dibaca. Program menangkap ValueError, menampilkan alasan, dan mengulang menu. Pada langkah ini keadaan sebelum dan sesudah sama.
