BAB 07 / 12

Bedah tampilan.py

Rapikan menu dan angka Rupiah tanpa mengubah data.

TUJUAN BELAJAR

Memisahkan nilai bilangan dari cara menampilkannya.

SEBELUM MULAI

Kenali fungsi, perulangan, dan f-string: teks berawalan f yang menyisipkan nilai lewat kurung kurawal.

Satu aturan format

rupiah menerima bilangan bulat dan mengembalikan string. abs menghapus tanda sementara, format :, menyisipkan koma per ribuan, replace menggantinya dengan titik. Tanda minus ditambahkan sebelum Rp hanya untuk nilai negatif. Nilai untuk perhitungan tetap int.

Komponen menu yang bisa dipakai ulang

OPS adalah tuple, yaitu urutan tetap yang mirip list tetapi elemennya tidak dapat diganti. enumerate(OPS, start=1) memberi angka mulai dari 1, bukan indeks biasa yang mulai dari 0. menu mencetak baris, jadi fungsi ini tidak mengembalikan teks menu.

Mengapa dipisah?

main.py tidak perlu mengulang enam print setiap iterasi pada tubuh fungsi utama. laporan.py memakai rupiah yang sama, sehingga saldo, riwayat, dan laporan kategori punya aturan format konsisten. Mengubah label visual tidak mengubah saldo. Jika urutan label diubah, selaraskan cabang pilihan di main.py.

Kode lengkap: tampilan.py

Simpan dengan nama ini bersama tiga file lainnya. Jalankan python3 main.py dari folder proyek; modul ini dipanggil sebagai bagian dari aplikasi, bukan program terminal terpisah.

tampilan.py
Unduh 
"""Komponen teks terminal, tanpa mengubah transaksi."""

OPS = ('Catat pemasukan', 'Catat pengeluaran', 'Lihat saldo',
       'Lihat riwayat', 'Laporan kategori', 'Keluar')


def rupiah(nilai):
    return f"{'-' if nilai < 0 else ''}Rp{abs(nilai):,}".replace(',', '.')


def menu():
    print('\n=== PENCATAT KEUANGAN ===')
    for nomor, label in enumerate(OPS, start=1):
        print(f'{nomor}. {label}')

Panduan membaca baris

Baris 3–4 · Label pilihan

Tuple menyimpan enam label. Nomor dihasil­kan dari posisi label, sehingga urutannya harus cocok dengan cabang di main.

Contoh kode
OPS = ('Catat pemasukan', 'Catat pengeluaran', 'Lihat saldo',
       'Lihat riwayat', 'Laporan kategori', 'Keluar')
Baris 7–8 · rupiah(nilai) → str

abs memastikan pemisah ribuan bekerja pada besar nilai; tanda minus muncul di depan Rp. Angka 0 menjadi Rp0 tanpa tanda tambahan.

Contoh kode
def rupiah(nilai):
    return f"{'-' if nilai < 0 else ''}Rp{abs(nilai):,}".replace(',', '.')
Baris 11–14 · menu() → None

Tidak menerima input. print judul, enumerate membaca label sambil menghitung mulai 1, dan print memformat nomor serta label. Tidak membaca list transaksi.

Contoh kode
def menu():
    print('\n=== PENCATAT KEUANGAN ===')
    for nomor, label in enumerate(OPS, start=1):
        print(f'{nomor}. {label}')

Contoh yang disiapkan

Ini contoh materi, bukan hasil eksekusi di browser.

rupiah(125000) → "Rp125.000"
rupiah(-25000) → "-Rp25.000"
rupiah(0) → "Rp0"
UJI PEMAHAMAN

Coba jawab dulu

Bolehkah menjumlahkan hasil rupiah(25000) dengan 150000?

Lihat pembahasan

Tidak. Hasil rupiah() berupa string untuk dibaca manusia. Jumlahkan bilangan dulu, lalu format hasil akhir.
