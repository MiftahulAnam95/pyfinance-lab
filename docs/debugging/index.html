Error & Debugging

Baca pesan error dan temukan penyebabnya.

TUJUAN BELAJAR

Mengenali sintaks, runtime, dan logika serta memilih langkah perbaikan.

SEBELUM MULAI

Pahami dasar input, kondisi, dan fungsi.

Sintaks: Python belum mulai menjalankan file

if pilihan == "3" tanpa titik dua menimbulkan SyntaxError. Baca nama file dan nomor baris, perhatikan tanda ^, lalu periksa juga baris sebelumnya. Indentasi blok yang tidak konsisten dapat menimbulkan IndentationError. Gunakan empat spasi per tingkat.

Runtime: program berhenti saat menjalankan baris

int("25.000") menghasilkan ValueError; operasi valid secara sintaks, tetapi nilainya tidak cocok. Pada proyek, baca_nominal menolak teks itu lebih dulu dan main menangkap ValueError. Jika melihat traceback, mulai dari baris terakhir untuk nama dan pesan error, lalu temukan baris kode milikmu.

Logika: jalan, tetapi hasilnya keliru

Jika cabang pengeluaran memakai total += item['nominal'], saldo demo menjadi Rp175.000, bukan Rp125.000. Python tidak tahu aturan bisnis. Mulai dari data terkecil dan bandingkan nilai aktual dengan hitungan manual.

Langkah investigasi

Catat input serta hasil yang kamu harapkan. Ulangi dengan satu kasus kecil. Gunakan print(repr(pilihan)) untuk melihat kutip/spasi yang tersembunyi, atau print(data) setelah tambah. Perbaiki satu hal, uji kasus normal dan kasus kosong, lalu hapus print debug.

Contoh yang disiapkan

Ini contoh materi, bukan hasil eksekusi di browser.

>>> int("25.000")
ValueError: invalid literal for int() with base 10: '25.000'
>>> int("25000")
25000

Coba jawab dulu

Saldo salah, tetapi tidak ada traceback. Mulai dari mana?

Lihat pembahasan

Ini mungkin kesalahan logika. Bandingkan setiap langkah saldo dengan penjumlahan manual; cek jenis transaksi dan tanda operasi.
