Dasar Python

TUJUAN BELAJAR

SEBELUM MULAI

Kenali cara menjalankan Python dari bab Persiapan.

Cara memakai bab ini

Salin satu cuplikan ke file latihan terpisah dan jalankan. Cuplikan import perlu diletakkan di folder proyek. Sebelum menekan Enter, tebak tipe atau nilai data pada tiap langkah. Dua potong kode bisa terlihat mirip tetapi berbeda karena tanda kutip atau indentasi.

Delapan konsep, satu proyek

1. print dan input

print mengirim teks ke layar; input membaca satu baris sebagai string. Program perlu keduanya untuk berdialog.

Bayangkan: Seperti kasir yang bertanya nominal lalu membacakan kembali jawabanmu.

Urutan: input menampilkan prompt, menunggu Enter, lalu menyerahkan teks ke variabel. print menerima label dan teks, memisahkannya dengan spasi.

Contoh kode
teks = input("Nominal (Rp): ")
print("Kamu mengetik:", teks)

Input: 25000 → Kamu mengetik: 25000

Baca kode: Baris 1 menunggu jawaban lalu menyimpan string. Baris 2 hanya menampilkan, tidak mengubah isi teks.

Di proyek: main membaca pilihan dan nominal; tampilan mencetak daftar menu.

Hindari: Jangan menganggap hasil input berupa angka. Pakai int setelah validasi jika perlu berhitung.

Cek paham: Apa tipe data jawaban 25000?

String. Teks terlihat seperti bilangan tetapi berasal dari input.

2. Variabel dan tipe data

Variabel memberi nama pada sebuah nilai. Tipe menentukan operasi yang masuk akal: int untuk bilangan bulat, str untuk teks, bool untuk benar/salah.

Bayangkan: Nama variabel seperti label kotak; label “makan” berbeda dari jumlah uang di kotak.

Urutan: Simpan angka, simpan teks, lalu bandingkan hasil cek. Perbandingan menghasilkan bool.

Contoh kode
nominal = 25000
kategori = "Makan"
sah = nominal > 0
print(kategori, nominal, sah)

Tanpa input terminal → Makan 25000 True

Baca kode: Baris 1 tidak memakai kutip, jadi int. Baris 2 memakai kutip, jadi str. Baris 3 mengevaluasi perbandingan.

Di proyek: Dictionary transaksi menyimpan nominal sebagai int agar bisa dihitung dan kategori sebagai str agar bisa dikelompokkan.

Hindari: 25000 dan "25000" tidak setara. Jangan memberi titik ribuan pada literal Rupiah; 25.000 dibaca float 25.0.

Cek paham: Apakah "0" == 0 bernilai True?

Tidak. Keduanya berbeda tipe: teks vs bilangan.

3. Operator dan perhitungan

Operator melakukan aksi, misalnya + menambah, - mengurangi, dan > membandingkan. Proyek perlu aturan pengaruh transaksi terhadap saldo.

Bayangkan: Uang masuk berarti penambahan isi dompet; uang keluar berarti pengurangan.

Urutan: Mulai dari nilai yang sudah masuk, kurangi biaya, lalu lihat apakah hasil positif. += menyingkat pembaruan saldo.

Contoh kode
saldo = 0
saldo += 150000
saldo -= 25000
print(saldo, saldo > 0)

Tanpa input → 125000 True

Baca kode: Baris 2 setara saldo = saldo + 150000. Baris 3 memperbarui saldo dengan pengurangan. Baris 4 mencetak angka lalu hasil cek.

Di proyek: Fungsi saldo memakai += atau -= sesuai jenis item.

Hindari: Jangan memakai + pada dua teks nominal; "150000" + "25000" menggabungkan teks, bukan menjumlahkannya.

Cek paham: Apa hasil 150000 − (25000 + 10000)?

115000. Isi kurung dievaluasi dahulu menjadi 35000.

4. if, elif, dan else

Kondisi memilih tindakan. if memeriksa syarat pertama, elif syarat berikutnya, else menangani sisanya.

Bayangkan: Tombol lift: tekan lantai 3, lift menuju 3; tombol lain menghasilkan tujuan lain.

Urutan: Ambil pilihan sebagai teks. Periksa urut dari atas; jalankan hanya blok pertama yang tepat.

Contoh kode
pilihan = input("Menu: ")
if pilihan == "3":
    print("Lihat saldo")
elif pilihan == "6":
    print("Keluar")
else:
    print("Pilihan lain")

Input: 6 → Keluar

Baca kode: Baris 2 dan 4 menggunakan == untuk membandingkan. Baris berindentasi adalah isi cabang.

Di proyek: main memilih tindakan 1 sampai 6 dan memberi pesan ketika masukan tak dikenal.

Hindari: Gunakan ==, bukan =, dan tulis : di akhir kondisi. Gunakan empat spasi di baris isi.

Cek paham: Jika input 3, apakah else dijalankan?

Tidak. Setelah if cocok, cabang lain dilewati.

5. List dan dictionary

List menyimpan urutan item. Dictionary mengaitkan kunci dengan nilai. Gabungan keduanya membuat buku transaksi yang bisa ditelusuri.

Bayangkan: List seperti buku kas berurutan; dictionary seperti formulir dengan kolom bernama.

Urutan: Buat daftar kosong, tambahkan satu dictionary, ambil item pertama lalu baca kunci kategori.

Contoh kode
data = []
data.append({"jenis": "keluar", "nominal": 25000, "kategori": "Makan"})
print(data[0]["kategori"])

Tanpa input → Makan

Baca kode: Baris 2 menambahkan item terakhir. Baris 3 memakai indeks 0 untuk memilih item pertama, lalu kunci untuk memilih informasi.

Di proyek: tambah memasukkan dictionary; riwayat dan saldo mengunjungi item yang sama.

Hindari: data[0] pada list kosong memicu IndexError; nama kunci salah bisa memicu KeyError. Cek bentuk data.

Cek paham: Berapa len(data) setelah tambah satu transaksi?

1. Tiga kunci pada item tidak menambah jumlah item di list.

6. Perulangan for dan while

for mengunjungi setiap item; while mengulang selama syarat benar. Yang pertama cocok untuk laporan, yang kedua untuk menu.

Bayangkan: Baca semua baris buku satu per satu; buka kasir terus sampai ada perintah tutup.

Urutan: for mencetak dua nominal. while True membaca pilihan berulang sampai break pada pilihan 6.

Contoh kode
for nominal in [150000, 25000]:
    print(nominal)
while True:
    if input("Menu: ") == "6":
        break

Output awal: 150000 lalu 25000. Input 6 mengakhiri loop.

Baca kode: Baris 1 mengganti nominal pada tiap putaran. Baris 3 selalu benar; baris 5 menyediakan jalan keluar.

Di proyek: saldo dan laporan memakai for; main mengulang menu dengan while.

Hindari: while True tanpa break yang bisa tercapai membuat menu tidak bisa keluar normal.

Cek paham: Jika list kosong, berapa kali isi for berjalan?

Nol. Tidak ada item yang bisa dibaca.

7. Fungsi dengan def

Fungsi memberi nama pada potongan pekerjaan yang bisa dipanggil berkali-kali. Parameter menerima masukan, return mengirim hasil.

Bayangkan: Resep: masukkan dua bahan, ikuti aturan, kembalikan hasil kepada pemesan.

Urutan: def menyimpan aturan. Pemanggil mengirim dua bilangan; fungsi mengurangi dan mengembalikan angka, lalu print menampilkannya.

Contoh kode
def sisa(masuk, keluar):
    return masuk - keluar

hasil = sisa(150000, 25000)
print(hasil)

Tanpa input → 125000

Baca kode: Baris 1 menyebut parameter. Baris 2 mengakhiri fungsi dengan nilai. Baris 4 memanggil fungsi dengan argumen nyata.

Di proyek: saldo(data) mengembalikan angka; menu() justru mencetak teks. Keduanya punya tugas berbeda.

Hindari: Jika mengganti return dengan print, hasil tidak bisa dipakai sebagai angka: pemanggil menerima None.

Cek paham: Berapa nilai sisa(25000, 150000)?

-125000. Urutan argumen menentukan mana yang dikurangi.

8. import dan hubungan antarfile

Modul adalah file Python yang bisa diimpor. import memberi akses pada kode di file lain tanpa menyalin isinya.

Bayangkan: Pinjam satu alat dari kotak alat yang sudah dibuat.

Urutan: Simpan cuplikan di folder proyek. Python menemukan tampilan.py, mengambil fungsi rupiah, lalu cuplikan memanggilnya.

Contoh kode
from tampilan import rupiah
print(rupiah(125000))

Tanpa input → Rp125.000

Baca kode: Baris 1 memakai nama modul tanpa .py serta nama fungsi. Baris 2 memakai fungsi itu seperti fungsi lokal.

Di proyek: main mengimpor ketiga modul lain; laporan juga meminjam format rupiah dari tampilan.

Hindari: Jangan tulis from tampilan.py. Jika modul tidak ditemukan, cek nama dan direktori file.

Cek paham: Perlu menyalin fungsi rupiah ke laporan.py?

Tidak, import memakai satu implementasi yang sama sehingga aturan format tidak menyimpang.

Contoh yang disiapkan

Ini contoh materi, bukan hasil eksekusi di browser.

Masukan: 25000

int(...) menghasilkan bilangan 25000
