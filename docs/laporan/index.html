BAB 05 / 12

Bedah laporan.py

Ubah daftar transaksi menjadi laporan yang mudah dibaca.

TUJUAN BELAJAR

Membedakan daftar urut, akumulasi per kategori, serta total saldo.

SEBELUM MULAI

Pahami dictionary, for, dan format Rupiah.

Riwayat: tiap transaksi tetap terlihat

riwayat membuat list baris terpisah. enumerate mulai dari 1; tanda + atau - berasal dari jenis. join menyambungkan baris dengan pindah baris. Tidak satu pun item diurut ulang atau dihapus.

Kategori: akumulasi hanya pengeluaran

per_kategori memulai dictionary kosong, melewati pemasukan, dan menambahkan nominal pada nama kategori. get(nama, 0) berarti gunakan 0 jika nama itu belum tercatat. Dengan dua transaksi Makan sebesar 25.000 dan 10.000, total Makan menjadi 35.000. Nama kategori mempertahankan huruf besar/kecil, jadi “makan” berbeda dengan “Makan”.

Teks kosong dan status

Fungsi mengembalikan pesan khusus saat tak ada transaksi atau pengeluaran. Tidak ada status keuangan, target, atau grafik penilaian; laporan ini bukan nasihat finansial. main.py mencetak hasilnya, sementara format angka didelegasikan ke tampilan.py.

Kode lengkap: laporan.py

Simpan dengan nama ini bersama tiga file lainnya. Jalankan python3 main.py dari folder proyek; modul ini dipanggil sebagai bagian dari aplikasi, bukan program terminal terpisah.

laporan.py
Unduh 
"""Buat laporan teks dari daftar transaksi."""

from tampilan import rupiah


def riwayat(data):
    hasil = []
    for nomor, item in enumerate(data, start=1):
        tanda = '+' if item['jenis'] == 'masuk' else '-'
        hasil.append(f"{nomor}. {item['kategori']} | {tanda}{rupiah(item['nominal'])}")
    return '\n'.join(hasil) or 'Belum ada transaksi.'


def per_kategori(data):
    total = {}
    for item in data:
        if item['jenis'] == 'keluar':
            nama = item['kategori']
            total[nama] = total.get(nama, 0) + item['nominal']
    return '\n'.join(f'{nama}: {rupiah(n)}' for nama, n in total.items()) or 'Belum ada pengeluaran.'

Panduan membaca baris

Baris 3 · Pakai format yang sama

Impor rupiah dari tampilan. Tidak ada impor balik dari tampilan ke laporan, jadi tidak saling memanggil saat dimuat.

Contoh kode
from tampilan import rupiah
Baris 6–12 · riwayat(data) → str

Siapkan list keluaran; enumerate memasangkan 1 dengan item pertama. Bentuk setiap baris dengan f-string, lalu join. Jika hasil gabungan kosong, or mengembalikan pesan alternatif.

Contoh kode

Baris 14–20 · per_kategori(data) → str

Lewati jenis masuk. Ambil kategori sebagai kunci; Makan 25000 menjadi 35000 setelah Makan 10000. items memberi pasangan kunci dan nilai dalam urutan pertama kali ditambahkan. Saat hanya ada pemasukan, keluaran menyebut belum ada pengeluaran.

Contoh kode
